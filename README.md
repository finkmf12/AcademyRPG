## ✦ O projeto

O **Academy RPG** transforma a rotina de estudos em uma aventura. A proposta é unir organização, aprendizado e elementos clássicos de RPG em uma plataforma web com atmosfera de fantasia medieval.

Aqui, cada desafio concluído representa progresso. O conhecimento é sua principal habilidade — e cada nova conquista faz parte da jornada.

## ⚔️ O que você encontra na Academia

### 📚 Trilhas de conhecimento
- **Programação de Aplicativos**
- **Banco de Dados**
- **Modelagem de Sistemas**

### 🧙 Progressão e aventura
- Sistema de experiência (XP), níveis e moedas.
- Missões semanais com objetivos e recompensas.
- Arena dos Chefes com desafios ligados às disciplinas.
- Ranking geral, semanal e mensal.
- Guildas para reunir aventureiros e personalizar bandeiras.

### 🏰 Recursos da plataforma
- Acesso com conta Google.
- Modo visitante para conhecer a experiência.
- Biblioteca de estudos com arquivos por aluno.
- Sincronização na nuvem para contas autenticadas.
- Área exclusiva de gestão para o professor.

> O projeto está em evolução contínua. Novas áreas, desafios e recursos fazem parte da expansão do universo Academy RPG.

## 🛠️ Tecnologias

| Tecnologia | Utilização |
|---|---|
| **HTML5** | Estrutura da aplicação |
| **CSS3** | Interface, identidade visual e animações |
| **JavaScript** | Lógica, interações e sistemas do jogo |
| **Supabase** | Autenticação, banco de dados e persistência |
| **Vercel** | Hospedagem e publicação |

O projeto utiliza políticas de segurança no banco de dados e operações autenticadas para proteger dados e recompensas dos jogadores.

## 💻 Executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/finkmf12/AcademyRPG.git
   ```

2. Abra a pasta do projeto no VS Code.
3. Inicie o `index.html` com uma extensão de servidor local, como **Live Server**.
4. Para testar login e recursos online, utilize a configuração do projeto Supabase e os endereços locais autorizados no provedor de autenticação.

> Não publique chaves privadas ou credenciais do Supabase no repositório.

## 🗺️ Estrutura do projeto

```text
AcademyRPG/
├── index.html                 # Entrada principal (mantida na raiz para a Vercel)
├── README.md                  # Apresentação do projeto
├── assets/
│   ├── css/                   # Folhas de estilo
│   ├── js/                    # Módulos JavaScript
│   └── ...                    # Imagens e recursos visuais
├── database/                  # Scripts SQL do Supabase
└── docs/                      # Guias e documentação técnica
```

- `index.html` — página principal da aplicação.
- `academia-adventure.js` e `academia-adventure.css` — módulos e estilos da experiência de aventura.
- `academia-xp.js` e `academia-xp.css` — sistema de experiência e progressão.
- `setup.sql` e arquivos `supabase-*.sql` — estrutura e atualizações do banco de dados.
